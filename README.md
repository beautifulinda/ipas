# iPAS AI 應用規劃師（初級）主題地圖

以可縮放的知識地圖整理 iPAS AI 應用規劃師初級的考試範圍，並在每個主題概念下提供練習題。

> 本專案為個人製作的練習工具，與 iPAS 主辦單位無關，內容不代表官方立場。考試範圍與規定請以官方最新公告為準。

- 線上練習：`https://beautifulinda.github.io/ipas/`（待部署）
- 狀態：開發中（Phase 1）

## 解決的問題

準備考試時，條列式講義看不出各主題之間的關係，刷題網站則看不出自己在整體範圍中的弱項。本專案把考試範圍做成三層地圖，學習進度直接顯示在地圖上，換言之，打開地圖就知道哪一區還沒讀、哪一區常答錯。

## 功能

### 主題地圖（三層）

1. 第一層：科目（兩個科目）
2. 第二層：大知識分類
3. 第三層：主題概念，以及（可選）練習題

點擊節點後以動畫放大至下一層，上方麵包屑可隨時返回上一層。

### 依裝置切換檢視方式

| 項目 | 桌面版 | 手機版 |
| --- | --- | --- |
| 地圖瀏覽 | 整張地圖，滾輪縮放、拖曳平移 | 一次顯示一層，點擊鑽取進入下一層 |
| 返回上一層 | 麵包屑、Esc 鍵 | 左上角返回按鈕、右滑手勢 |
| 概念說明 | 右側面板，地圖保持可見 | 底部滑出面板（bottom sheet） |
| 練習作答 | 右側面板內作答 | 全螢幕作答 |
| 其他操作 | 方向鍵切換同層節點、滑鼠懸停提示 | 觸控目標至少 44px |

裝置判斷同時參考螢幕寬度與輸入方式（`pointer: coarse`），讓以觸控操作的平板也能套用手機版操作。另提供清單模式，可在兩種檢視間切換。

### 練習與進度

- 依主題練習，作答後立即顯示解析
- 錯題本與作答紀錄，存於使用者瀏覽器
- 匯出、匯入學習紀錄（JSON 檔），供使用者自行在不同裝置間轉移
- 模擬考模式：計時、計分、各主題答對率
- 節點依學習狀態顯示顏色：未練習、答對率高、常答錯

## 隱私設計

本專案採本機優先（local-first）設計，原則是不在伺服器保存可識別使用者的資料。

| 資料 | 存放位置 | 說明 |
| --- | --- | --- |
| 錯題本、作答紀錄、學習進度 | 使用者瀏覽器（IndexedDB） | 不上傳；清除瀏覽器資料後即消失，建議定期匯出 |
| 各題答對、答錯次數 | Supabase | 匿名統計，僅記錄題目 ID 與對錯，不記錄使用者身分 |
| 題目錯誤回報 | Supabase | 僅記錄題目 ID 與回報內容，不要求聯絡方式 |

- 不提供登入功能，不收集姓名、Email 等個人資料。
- 網站提供隱私說明頁，列出上述存放內容。

## 題目來源原則

- 題目由作者依官方公開的評鑑範圍與學習指引自行撰寫，可使用 LLM 輔助產生草稿，所有題目皆經人工審核後才納入題庫。
- 不轉載官方樣題或考題全文；如需引用，僅提供官方頁面連結。
- 每題標註來源類型（`original` 或 `official-link`）。

## 系統架構

```
[題庫 JSON] ──> [GitHub Actions：格式檢查、答案驗證、測試] ──> [nuxt generate] ──> [GitHub Pages]
                                                                                     │
                                                         （Phase 2）[Supabase：匿名答題統計、題目回報]
```

- GitHub Pages 僅提供靜態網站，前端不直接呼叫 LLM，避免 API key 外洩。
- LLM 輔助出題在本機或 CI 中執行，產出結果寫入題庫 JSON，經審核後提交。
- Phase 2 接入 Supabase 時，前端僅使用 anon key，所有資料表啟用 RLS：匿名資料表只允許新增、不允許讀取原始資料，統計數字一律透過彙總後的 view 或資料庫函式取得，並設有寫入頻率限制。

## 技術選型

- 前端：Nuxt 3、Vue 3、TypeScript
- 地圖：SVG、D3（d3-zoom、d3-hierarchy）
- 裝置判斷：VueUse `useMediaQuery`
- 測試：Vitest（資料與邏輯）、Playwright（手機與桌面尺寸 E2E）
- 部署：GitHub Actions、GitHub Pages
- 本機儲存：IndexedDB
- 後端（Phase 2）：Supabase（PostgreSQL、RLS）

## 資料結構

完整範例見 [`data/map.sample.json`](data/map.sample.json)，型別定義見 [`types/map.ts`](types/map.ts)。

```
Subject（科目）
└── Category（大知識分類）
    └── Concept（主題概念）
        └── Question[]（練習題，可為空陣列）
```

```bash
npm install

npm run test       # 單元測試
npm run generate   # 產生靜態網站
```
